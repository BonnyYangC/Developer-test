# Requirements

The application should display:

1. The participation rate (as a percentage) for the survey
2. The average rating (from 1 to 5) for each survey question

## The data

The data in [example-data/survey.csv](example-data/survey.csv) represents:

- One **survey**, which contains a list of **responses**
- Each **response** represents an individual user responding to the survey
  - It contains some employee and response data and **answers** to each question
  - Each **answer** represents an optional agreement rating on a scale of `"1"` (strongly disagree) to `"5"` (strongly agree).

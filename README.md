# Survey Tool - Node

_Please review the [main README](../../README.md) for overall instructions._

Welcome to the node starter kit for the survey tool exercise!

Included here is a simple CLI executable, a `src/cli.ts` to hold the beginnings of your
application logic, plus a Jest installation and a single failing integration test, which
should help you drive the beginning of your implementation.

## Prerequisites

- node (version specified in `.tool-versions`, but feel free to adjust the setup for your
  environment)

## Development

### Installing dependencies

``` sh
npm install
```

### Testing

``` sh
npm run test
```

### Running

``` sh
npm run start
```
